# SANKALP — AI-Powered Automatic Block Planning

Live demo: **https://hidhruvan-prog.github.io/sankalp-block-planner/**

Smart India Hackathon 2026 · Problem Statement 26027 · Ministry of Railways · Team CodeCraft

One plan for the block (line possession) demands of all three departments — Engineering,
S&T and Traction Distribution — instead of three separate requests. A survival model
estimates each defect's day-by-day failure probability; a two-stage CP-SAT optimiser solves
the due dates first as a proven floor, then fits the work around trains and routes.

**This page is a rendered snapshot of the working console.** The division, timetable, crew
limits, defects and due dates are **simulated** — not Indian Railways field data — and the
"rule-based baseline" it is compared against is our own model of current practice. Source
code is not published here.
